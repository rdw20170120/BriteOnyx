# ToDo items for this project

These are outstanding items of work for us to do.
This list is intended to be kept short and simple enough
that it can be visually scanned and managed.

Items should be checked-off and perhaps moved to the bottom when completed.
Items should be ~~struck-out~~ to indicate that they have been canceled,
unless they should merely be deleted.

Item order is designed so that sorting the items puts the next workable item first.
Order is no longer relevant once the item is completed, so remove it.

Order is a single character:

- `?` = order is still unknown (backlog)
- `A` = use Bash as primary shell
- `P` = item is paused (started but not finished or in-progress)
- `T` = begin using TypeScript for my advanced scripting needs
- digit = order priority where 1=soonest thru 9=latest

Use other characters for other meanings and purposes, but document them here first.
